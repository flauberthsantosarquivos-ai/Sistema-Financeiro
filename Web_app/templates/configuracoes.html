Testar conexão Google

Verifica se o sistema consegue acessar a planilha vinculada com as credenciais configuradas.

Alterar planilha vinculada

Permite trocar o link da planilha padrão usada pelo sistema. Esta função será usada em implantação de novos clientes.

Configurar importação de extratos

Define padrões para importação de extratos bancários, como conta padrão, regras de classificação e categorias sugeridas.

Abrir importação

Auditar BASE_LANCAMENTOS

Abre a base oficial do sistema para verificar se os lançamentos foram gravados corretamente por mês, origem, situação, previsto e realizado.
