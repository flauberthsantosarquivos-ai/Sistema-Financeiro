Fluxo recomendado de uso

Esta sequência ajuda a manter a base organizada e evita análises com dados incompletos.

1

Importar Extratos

Envie o arquivo XLS, XLSX ou CSV do banco. O sistema lê o extrato, aplica regras de classificação e mostra uma prévia antes de gravar.

Importar agora
2

Revisar Base

Confira os lançamentos importados, ajuste categorias, resolva itens “A CLASSIFICAR”, edite valores e exclua registros incorretos.

Revisar base
3

Novo Lançamento

Cadastre manualmente receitas, despesas, previsões ou ajustes que não vieram no extrato bancário.

Adicionar lançamento
4

Análise Financeira

Veja indicadores, gráficos, despesas por categoria, saldo do período e diagnóstico financeiro com base nos lançamentos revisados.

Ver análise

Como usar no dia a dia

A Central Financeira foi organizada para reduzir retrabalho. Primeiro os dados entram, depois são revisados, e só então os gráficos são usados para tomada de decisão.

✓ Importe o extrato do banco e confira a prévia antes de confirmar.
✓ Use a Base de Lançamentos para corrigir classificações e excluir registros desnecessários.
✓ Cadastre manualmente despesas ou receitas que não aparecem no extrato.
✓ Depois de revisar a base, acesse a Análise Financeira para ver gráficos e diagnóstico.

Atenção

Antes de analisar os gráficos, revise os lançamentos classificados como A CLASSIFICAR. Eles podem distorcer os diagnósticos financeiros.
