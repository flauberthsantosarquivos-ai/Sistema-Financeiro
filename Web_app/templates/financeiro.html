Fluxo de trabalho recomendado

Siga as etapas abaixo na ordem para manter a base organizada e a análise financeira confiável.

1

Importar extrato

Leia o extrato bancário, aplique regras de classificação e gere uma prévia antes de gravar.

Ir para extratos
2

Revisar base de lançamentos

Ajuste tipo, categoria, subcategoria, situação e valores antes de analisar os dados.

Revisar base
3

Novo lançamento manual

Cadastre receitas, despesas, transferências ou ajustes que não vieram pelo extrato.

Novo lançamento
4

Orçamento mensal

Informe os valores previstos por mês, categoria e subcategoria para comparar com o realizado.

Cadastrar orçamento

Análise financeira

Veja indicadores, orçamento por categoria, evolução mensal, composição das despesas e diagnóstico.

Abrir análise

Conferência final

Após a análise, volte à base para corrigir lançamentos a classificar ou categorias inconsistentes.

Corrigir pendências

Como usar esta central

A Central Financeira foi organizada para evitar perda de sequência operacional. A configuração da planilha vem antes de qualquer etapa, porque todo o sistema depende dela.

1 Configure ou confirme a planilha vinculada.
2 Importe o extrato e revise a prévia antes de gravar.
3 Revise a base para corrigir classificações, tipos e situações.
4 Cadastre o orçamento mensal para alimentar o previsto.
5 Consulte a análise financeira com dados realizados e planejados.

Estrutura de dados

A análise financeira usa a base de lançamentos para o realizado e o orçamento mensal para os valores previstos.

✓ BASE_LANCAMENTOS: receitas, despesas, transferências e extratos importados.
✓ ORCAMENTO_MENSAL: valores previstos por mês e categoria.
✓ Análise: compara previsto x realizado e gera diagnóstico.
